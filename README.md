# forge-dashboard-e2e-fixture

Throwaway pull requests in every state a pull request can reasonably be in.
[`alrayyes/forge-dashboard`](https://github.com/alrayyes/forge-dashboard)
checks its view of each one against what GitHub says.

Nothing here is a project. The branches, rulesets and pull requests are built
by a script in forge-dashboard (`scripts/e2e-fixture/`), and can be wiped and
rebuilt. Don't merge anything in here by hand.
